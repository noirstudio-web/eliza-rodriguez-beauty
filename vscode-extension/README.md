# Eliza Beauty – Clientas

Sección exclusiva en la barra lateral de VS Code para gestionar las cuentas de clientas y la fidelidad de Eliza Rodriguez Beauty.

- Entra con el usuario y la contraseña del panel de admin.
- Crear cuentas, cambiar contraseñas, sumar o quitar sellos, entregar regalos y activar o desactivar cuentas.
- Envía el usuario y la contraseña a la clienta por WhatsApp.
